# Placeholder-Page (Halteseite) für „Schaufenster“

Eine einfache statische Halteseite, die bei Bedarf anstelle des Hauptprojekts „Schaufenster“ ausgeliefert werden kann. Die Halteseite ist unabhängig vom Nuxt-Build des Hauptprojekts.    

## Lokale Entwicklung
```bash
cd schaufenster/placeholder-page
npm install
npm run dev
```
Bitte an den CSS-Variablen und Klassen des Hauptprojekts orientieren und diese bei Bedarf in das Projekt übernehmen.
